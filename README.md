# Imparare Python con progetti pratici

Un percorso a lezioni, pensato per chi arriva da PHP e VB.NET, verso l'uso di Python
con le API della PA (PDND Interoperabilità) e l'intelligenza artificiale.
Ogni cartella è un progetto completo e funzionante, con istruzioni ed esercizi.

| # | Lezione | Cosa costruisci |
|---|---|---|
| 1 | [Gestore spese](01-gestore-spese/) | programma con finestra grafica, file JSON, test |
| 2 | [Client PDND](02-client-pdnd/) | client assertion, voucher e chiamata a un e-service, con simulatore locale |
| 3 | *in arrivo* | voucher DPoP e header del Modello di Interoperabilità (audit, integrità) |
| 4 | *in arrivo* | AI sui documenti: riassunti ed estrazione di dati con l'API di Claude |
| 5 | *in arrivo* | assistente AI che interroga gli e-service |

## Come scaricare il codice

Pulsante verde **Code → Download ZIP** su GitHub, poi estrai lo ZIP ed entra nella cartella della lezione.
